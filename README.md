# Logistics & Freight Analytics Dashboard

## Project Overview

This project is a logistics and freight analytics dashboard developed using Microsoft Power BI.

The objective of the project was to transform logistics and operational data into an interactive business intelligence report that can be used to monitor performance, identify trends, and support data-driven decision-making.

## Business Problem

Logistics companies generate large amounts of operational and financial data. Without effective reporting and visualization, it can be difficult to understand revenue performance, customer activity, transportation costs, and operational efficiency.

This project uses Power BI to bring relevant logistics data together into an interactive dashboard and present key performance indicators in an easy-to-understand format.

## Project Objectives

The main objectives of the project were to:

- Analyze logistics and freight operations.
- Monitor key business performance indicators.
- Analyze revenue and profitability.
- Evaluate customer performance.
- Examine operational efficiency.
- Identify trends and patterns in the data.
- Present findings through an interactive Power BI dashboard.

## Tools & Technologies

- Microsoft Power BI

- DAX
- Data Modeling

## Data

The project was developed using multiple interconnected CSV datasets representing different aspects of logistics and freight operations.

The datasets were imported into Power BI, transformed using Power Query, and connected through a relational data model.

## Data Preparation

The data preparation process included:

- Importing multiple CSV files.
- Cleaning and transforming the datasets using Power Query.
- Preparing tables for analysis.
- Establishing relationships between tables.
- Resolving data relationship issues.
- Creating calculated measures using DAX.

## Data Analysis

DAX measures were created to support the analysis of important logistics metrics, including:

- Revenue
- Fuel Cost per Mile
- Maintenance Cost per Mile
- Downtime
- Detention Time
- On-Time Delivery Performance

## Dashboard

The final Power BI report is an interactive multi-page dashboard designed to provide users with a clear view of logistics and freight performance.

Users can interact with the report to explore different aspects of the business and identify trends and performance patterns.

## Key Areas Analyzed

### Revenue Performance

The dashboard provides analysis of revenue performance over time and allows users to examine revenue across different customers and freight categories.

### Customer Performance

Customer-level analysis helps identify important customers and compare their contribution to overall business performance.

### Operational Performance

Operational metrics are used to evaluate areas such as delivery performance, downtime, detention time, and transportation efficiency.

### Cost Analysis

The dashboard examines transportation-related costs, including fuel and maintenance costs, to help identify areas that may require further investigation.
