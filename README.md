# 📊 Logistics & Freight Analytics Dashboard

## Overview

This project is an interactive logistics and freight analytics dashboard developed using Microsoft Power BI.

The dashboard transforms logistics data into meaningful business insights that can be used to monitor revenue, profitability, customer performance, transportation costs, and operational efficiency.

## 🎯 Business Problem

Logistics companies generate large amounts of operational and financial data. Without effective analysis and reporting, it can be difficult to identify performance trends, cost issues, customer patterns, and operational inefficiencies.

This project uses Power BI to transform raw logistics data into an interactive dashboard that supports data-driven decision-making.

## 🎯 Project Objectives

- Analyze logistics and freight operations.
- Monitor key performance indicators.
- Analyze revenue and profitability.
- Evaluate customer performance.
- Examine operational efficiency.
- Analyze fuel and maintenance costs.
- Identify trends and areas requiring improvement.
- Present insights through interactive visualizations.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Microsoft Excel
- CSV datasets

## 📂 Dataset

The project uses multiple interconnected CSV datasets representing different aspects of logistics and freight operations.

The datasets were imported into Power BI and transformed using Power Query before being connected through a relational data model.

## 🔄 Data Preparation

The data preparation process included:

- Importing multiple CSV files.
- Cleaning and transforming data using Power Query.
- Preparing tables for analysis.
- Establishing relationships between tables.
- Resolving data relationship issues.
- Creating calculated measures using DAX.
