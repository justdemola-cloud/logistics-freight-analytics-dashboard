# 📊 Logistics & Freight Analytics Dashboard

## Project Overview

This project is an interactive **Power BI logistics and freight analytics dashboard** developed to analyze the operational and financial performance of a US trucking company.

The dashboard transforms data from **15 interconnected CSV files** into interactive reports covering revenue, profitability, customer performance, driver and delivery operations, fuel and maintenance costs, downtime, detention time, and safety performance.

The goal was to turn raw logistics data into meaningful insights that can support operational monitoring and data-driven business decisions.

---

## 🎯 Business Problem

Logistics companies generate large volumes of operational, financial, customer, and transportation data.

Without an effective reporting system, it can be difficult to:

- Monitor revenue and profitability.
- Identify major cost drivers.
- Evaluate customer and driver performance.
- Track delivery and safety performance.
- Understand fuel and maintenance expenses.
- Identify operational inefficiencies.

This project uses Power BI to bring these different data sources together into an interactive analytical dashboard.

## 📂 Dataset

The project uses **15 interconnected CSV datasets** representing different aspects of logistics and freight operations.

The datasets were imported into Power BI and transformed using Power Query before being connected through a relational data model.

### Data preparation included:

- Importing multiple CSV files.
- Cleaning and transforming raw data.
- Preparing tables for analysis.
- Establishing relationships between tables.
- Resolving table relationship ambiguities.
- Creating calculated measures using DAX.
- Building KPIs for operational and financial analysis.
